# Background and dataset
All three group members had an interest in ecology, oceanopgraphy, and wildlife. Therefore, we went on the Data.gov website and looked for a California Department of Fish and Wildlife dataset. We chose a dataset that analyzes shark attack incidents in California from the year 1950 to 2022. The dataset includes information on the date, time, location, water depth, human activity, injury (if any), species of shark, and source information. The dataset is called the [CDFW Shark Incident Database - California](https://catalog.data.gov/dataset/shark-incident-database-california?from_hint=eyJxIjoic2hhcmsiLCJzb3J0IjoicmVsZXZhbmNlIiwic2x1ZyI6ImNhbGlmb3JuaWEifQ%3D%3D)

We chose this dataset becuase it was clear, concise, and relatively clean. The dataset definitely did require some cleaning but it was overall a very presentable dataset.
